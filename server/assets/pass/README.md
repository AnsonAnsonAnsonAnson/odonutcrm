Optional brand art for the wallet pass. Any file here replaces the generated default:

- `icon.png`: square, at least 87x87 (shown in notifications and on the lock screen)
- `logo.png`: your logo on a transparent background, wide, at least 480x150
- `stamp-on.png` / `stamp-off.png`: square artwork for a collected / empty stamp (e.g. a pink donut and a grey donut)

Restart the app after changing files. Every pass picks up the new art the next time it refreshes.
